# Documentation Index

Welcome! These pages summarise the tools covered in the Technical Writing course.

1. [LaTeX](latex.md) – typesetting professional documents
2. [Beamer](beamer.md) – presentations with LaTeX
3. [Doxygen](doxygen.md) – generating documentation from source code
4. [Google Docs](google-docs.md) – collaborative cloud writing
5. [Git](git.md) – local version control
6. [GitHub](github.md) – hosting, collaboration and project management

**Suggested workflow:** write reports in LaTeX → present them with Beamer → document code with
Doxygen → collaborate on drafts in Google Docs → track everything with Git → publish on GitHub.
