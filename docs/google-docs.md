# Google Docs

## 1. Overview
Google Docs is a free, browser-based word processor that is part of Google Workspace. Documents are
saved automatically to Google Drive and can be edited by many people simultaneously.

## 2. Key features
- **Real-time collaboration:** multiple editors, coloured cursors, live chat
- **Auto-save and version history:** *File → Version history → See version history*
- **Sharing:** Viewer / Commenter / Editor roles; link sharing or specific people
- **Comments and suggestions:** *Suggesting* mode works like tracked changes
- **Offline mode** via Chrome extension, **access anywhere** from any device
- **Export:** `.docx`, `.pdf`, `.odt`, `.txt`, `.html`, `.epub`

## 3. Formatting and structure
- Use built-in **Heading styles** (Title, Heading 1–6) rather than manual bold text
- Insert a **Table of Contents** (*Insert → Table of contents*) that updates automatically
- Headers/footers, page numbers, footnotes, bookmarks and hyperlinks
- Tables, drawings, images, charts linked from Google Sheets
- Page setup: margins, orientation, paper size

## 4. Useful tools
- **Voice typing** (*Tools → Voice typing*)
- **Spelling and grammar**, **word count** (Ctrl+Shift+C)
- **Explore** / **Research** tools and **Translate document**
- **Add-ons**, e.g. Zotero or Mendeley for citations; **Citations** feature for APA/MLA/Chicago
- **Templates gallery** for resumes, reports and letters

## 5. Best practices for collaboration
1. Name files clearly (`Project_Report_v1`).
2. Use *Suggesting* mode when editing someone else's work.
3. Resolve comment threads once handled.
4. Assign action items with `@mentions` and the *Assign as action item* option.
5. Set the minimum permissions necessary when sharing.

## 6. Google Docs vs LaTeX
| | Google Docs | LaTeX |
|---|---|---|
| Learning curve | Very low | Steeper |
| Collaboration | Excellent, real-time | Good with Overleaf/Git |
| Maths & citations | Basic | Excellent |
| Layout control | Moderate, visual | Precise, automated |
| Best for | Drafts, team documents | Papers, theses, long documents |

## 7. Keyboard shortcuts
`Ctrl+B/I/U` bold/italic/underline · `Ctrl+K` link · `Ctrl+Alt+M` comment ·
`Ctrl+Z/Y` undo/redo · `Ctrl+F` find · `Ctrl+Alt+1..6` headings.
